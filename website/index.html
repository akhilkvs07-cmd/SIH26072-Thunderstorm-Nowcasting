What it does

From weather signals to risk insight

A demonstrator workflow for exploring the potential of machine learning in severe-weather awareness.

01 / INPUT

Atmospheric indicators

Explore weather variables such as CAPE, humidity, temperature, wind and pressure in a structured dataset.

02 / MODEL

ML-based estimation

A baseline classification pipeline demonstrates how weather features can be used to estimate a risk category.

03 / OUTPUT

Visual risk dashboard

Review risk estimates, geographic patterns, evaluation metrics and uploaded sample data in one interface.

Methodology

Prototype pipeline

Weather dataset→Data cleaning→Feature engineering→ML classifier→Risk visualization
Technology

Built with accessible tools

PythonScikit-learnStreamlitPandasPlotlyGitHub Actions

The codebase is organized into data, feature engineering, modelling, evaluation and dashboard modules.

Important limitation

Research prototype — not an alert service

The current demonstration uses synthetic sample data. It is not connected to operational radar, satellite, lightning or weather-station feeds, and its outputs must not be used for public safety decisions.
